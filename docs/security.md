# 输入与资源模型

默认头部上限 65,536 字节、样本数 1,000,000、载荷 64,000,000 字节。用户可按请求传 Limits，检查发生在尺寸乘积、载荷解码、变换输出分配之前。ASCII token 也有长度约束。原始输入缓冲区、Double 样本、所有权复制及各变换的临时数组需要额外内存，因此 Limits 不是总内存配额或 CPU 截止时间；服务端应同时限制请求字节和并发。

头部文本限定 ASCII，拒绝控制字符、重复字段、不安全自定义键和有歧义文件计划。detached 数据必须显式传入；仅接受安全 basename，且库从不打开它。上层如需读取文件，仍须在自己的受限根目录实施路径与文件权限策略。

不支持的压缩编码和跳过策略明确返回 Unsupported；不提供解压炸弹入口。整数转换严格验证，不使用静默截断。浮点 NaN/Inf 在浮点数据中允许，并在统计中单列，空间向量必须有限。世界坐标或求和溢出明确报错。

当前输入限制与测试不能保证消除所有缺陷。报告问题时请提供最小公开样例、工具链版本、目标后端、Limits 与复现命令，避免提交隐私数据或凭据。
